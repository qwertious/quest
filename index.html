QUEST DEMO

Qwertious Unified Extraction and Scanning Tool

Congratulations! You are on a QUEST!

Purpose

QUEST is a web extraction system used for content archiving and search indexing. It helps create searchable references of publicly accessible web pages.

What QUEST Collects

  • Page URL and page title
  • Main visible text content from public pages
  • Short summaries and extracted keywords
  • Timestamps of when a page was processed

What QUEST Does Not Collect

  • Private login-protected content
  • Form submissions or account credentials
  • Non-public data behind authentication barriers

Responsible Crawling

  • Follows links across websites and subdirectories
  • Uses request delays to reduce server impact
  • Reads and respects robots.txt directives

Questions or Concerns

If you have questions, want clarification, or need to report a concern regarding QUEST crawling behavior, contact the operator of this QUEST instance at you@example.org.

This page is provided for transparency about QUEST data collection and crawling practices.
